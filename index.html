odd-ws

Que tu agente no vuelva a cometer el mismo error

Un plugin que convierte lo que aprendes en un proyecto en chequeos que corren solos, en vez de notas que el agente tiene que recordar.

Para Claude Code, Codex CLI y gentle-shell (Pi). Código abierto, licencia MIT.

Ver el repo en GitHub Instalar Versiones

Cómo funciona

Una convención que solo vive como texto depende de que el modelo la recuerde. odd-ws sigue el principio mecanismo antes que memoria: lo que se aprende se vuelve un chequeo, no un recordatorio.

1El agente comete un error
2Lo corriges en el ticket
3/odd-ws:cerrar lo gradúa
4Se vuelve un chequeo, una skill o un revisor
5Corre solo en el próximo ticket

Qué te da

  • Cada ticket tiene su carpeta, con su objetivo, sus criterios de aceptación y su alcance.
  • Los hooks chequean cada edición contra las reglas de su capa, y frenan los comandos peligrosos.
  • Los cambios grandes los escriben agentes con compuerta, y los revisores dejan un recibo atado al diff.
  • Lo aprendido en un ticket sube a reglas y docs verificables.
  • Las reglas de un stack se pueden traer de otro repo git, fijadas a una etiqueta.

Dónde va la instancia

odd-ws monta una instancia, un espacio de trabajo con agentes, en una carpeta aparte, al lado de tus repos de código. La instancia tiene su propio git y apunta a tus repos por su ruta, sin tocarlos.

mi-proyecto-ws/
La instancia: tickets, reglas, agentes y su propio git.
apunta por su ruta →
mi-proyecto/
Tu repo de código, intacto.

Si la creas dentro de un repo de código, pierde su git: el bootstrap no le hace git init, ni configura el hook, ni hace el primer commit.

Instalar

Necesitas Python (invocable como python3, 3.7 o más) y Git. Los requisitos de cada CLI están en el README.

Con Claude Code
  1. Crea la carpeta de la instancia, aparte de tus repos (puede estar vacía), y desde ahí instala el plugin. --scope project es obligatorio: sin él, los hooks correrían en todos tus proyectos. 
    claude plugin marketplace add sebasgc0399/odd-workspace-template
claude plugin install odd-ws@odd-workspace-template --scope project
  2. Abre claude en esa carpeta y corre /odd-ws:bootstrap. Detecta tus repos, te muestra la propuesta completa y solo escribe después de tu sí, con el primer commit incluido.
  3. Corre /odd-ws:doctor, arregla lo que marque FALTA y abre tu primer ticket con /odd-ws:abrir.
Con Codex CLI
  1. Declara Codex en la instancia: "hosts": ["claude-code", "codex"] en workspace.config.json.
  2. Instala el plugin en Codex: 
    codex plugin marketplace add sebasgc0399/odd-workspace-template
codex plugin add odd-ws@odd-workspace-template
  3. Abre codex en la raíz de la instancia, confía en la carpeta y confía los hooks de odd-ws desde /hooks. Las skills se invocan con $, por ejemplo $doctor.
Con gentle-shell (Pi)
  1. Declara Pi en la instancia: "hosts": ["claude-code", "pi"], o solo ["pi"].
  2. Instala gentle-shell con npm i -g gentle-pi y el paquete de odd-ws desde git, con la etiqueta de la versión: 
    gentle-shell install git:github.com/sebasgc0399/odd-workspace-template@odd-ws--v<versión>
  3. Abre gentle-shell en la raíz de la instancia, dale confianza con /trust y corre /skill:doctor.

Junto a gentle-ai y engram

odd-ws no reemplaza a ninguno de los dos: cada uno cubre una parte distinta, y ninguno es obligatorio.

HerramientaDe qué se encarga
gentle-aiCómo trabaja el agente: el flujo, la delegación y la revisión
engramQué recuerda el agente entre sesiones
odd-wsQué se exige en cada proyecto, con lo aprendido convertido en chequeos
